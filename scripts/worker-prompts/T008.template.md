## Your task

Build TradRL's **data plane**: ingest provider-neutral market events, store them durably and immutably, and make data lineage a first-class, queryable citizen. This is the foundation the Time Machine (T026/T029), replay world (T009) and research bodies (T021–T023) consume.

### packages/provenance — the lineage library

TypeScript, strict, zero runtime dependencies, no `any`, hand-rolled guards:

- **AdapterReference**: identity for a data source — adapter id/version, provider, entitlement class (`open | licensed | restricted`), license constraints (retention, redistribution flags). Entitlement-aware from day one: licensed data stays access-controlled (spec/ADAPTERS.md Licensing)
- **DataLineage**: dataset/event-stream lineage — what adapter produced it, what transforms derived it, derived-from chains with cycle/duplicate/orphan rules (mirror the semantics `@tradrl/market-protocol` established for event provenance, but for DATASETS and STREAMS)
- **SnapshotManifest**: an immutable, content-addressed description of a data snapshot — stream ids, event-count, content hash, time range (event_time min/max, available_time max), adapter references, entitlement summary. This is the artifact experiments bind for L9 (results bind data). Hash-stable: same content -> same manifest hash
- **EntitlementPolicy**: pure predicates — may this event/dataset be: copied into artifacts? retained past N? redistributed to tenants? Default-deny for licensed classes; typed violations
- **LineageError taxonomy**: typed errors (unknown adapter, entitlement violation, cycle in derived-from, hash mismatch…)
- **Registration**: adapter registry (id -> descriptor), versioned

### services/data-ingestion — the ingest pipeline

A minimal, dependency-free service package (library + CLI entry, no HTTP server this wave):

- **Ingest API**: accept raw provider records + an AdapterReference; normalize to the canonical MarketEvent shape (STRUCTURAL MIRROR of `@tradrl/market-protocol`'s envelope per D-004 — you may NOT add the package as a dependency; mirror the type declarations and write trip-wire tests that fail if they drift from the canonical source)
- **Validation gate**: full envelope validation before accept (the availability quartet is required; `available_time >= event_time` enforced; taxonomy payload validated per event type — mirror the registered validators)
- **Ingestion stamping**: `ingestion_time` is stamped HERE (at accept), never by the provider; dedup by event id; per-stream sequence discipline enforced via a mirrored sequence tracker (strictly increasing per `(venue, instrument, event stream)`; reject/flag violations — never silently reorder)
- **IngestReport**: per-batch report — accepted/rejected/dupe counts, rejection reasons (typed), stream coverage; deterministic given the same input batch
- **Syntheticity**: events ingested with `origin: simulated | generated` must carry their generation lineage (derived_from); `historical` events require the adapter reference — refuse otherwise
- **CLI**: `ingest <ndjson-file> --adapter <descriptor.json> [--stream out]` producing the batch report + normalized event stream

### services/event-store — the durable store

A minimal, dependency-free service package (library + CLI entry; durable via append-only files on local disk — no external database this wave):

- **Append-only event store**: immutable once written; content-addressed stream files (one file per stream) + a stream index; appends are atomic (write-then-rename or journal+compaction — your call, document it)
- **Point-in-time queries**: `query({ streams, from, to, asOf })` returns ONLY events whose `available_time <= asOf` — the store ENFORCES the L4 boundary at query time (zero future leakage even if a caller asks naively); also expose `countVisible` for boundary testing
- **Cursor/replay API**: deterministic cursor over a stream (ordered, resumable) — the primitive T009's replay world will consume
- **Store integrity**: load-verify (content hash per stream; detect corruption/truncation with typed errors); a `verify` CLI
- **Fixture-backed tests**: build a small synthetic fixture INSIDE your lane (clearly marked test fixture, not real data) — ingest it, query it as-of multiple times (including an asOf BETWEEN available_time values of two events — the boundary test), corrupt a file and verify detection
