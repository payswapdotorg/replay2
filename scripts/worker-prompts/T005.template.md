## Your task

Define the **environment protocol**: the contract between learning algorithms/agents and Market Worlds, plus a runner service skeleton. This is TradRL's gym-analog — but multi-fidelity (replay/reactive/generative) and point-in-time safe.

### packages/environment-protocol — the protocol

TypeScript, strict, zero runtime dependencies, no `any`, hand-rolled guards:

- **Environment interface family**: an environment is something you can `reset(config) -> Observation`, `step(action) -> StepResult(Observation, reward?, terminated, truncated?, info)` — BUT designed for TradRL's realities: observations are **point-in-time views** (respecting the availability boundary from time-engine), actions are typed per environment kind, and episode identity is lineage-bound (seed, config hash, world version)
- **FidelityMode**: the three DISTINCT modes (exact replay | reactive replay | generative) — never collapsed (L5)
- **Observation contract**: what an agent may see at simulation time t — designed to compose with `@tradrl/time-engine`'s VisibilityFilter concepts (reference structurally or by mirror + trip-wire test per D-004; do NOT add cross-package dependencies — the lockfile is frozen)
- **Action contract**: typed action spaces (at minimum: order-intent action for execution environments; discrete research/communication actions for organization environments); action validation with typed errors
- **RewardSpec**: reward is DATA (components + weights declared by the environment config), never a hidden global — multi-objective by design (return, risk, constraint violation penalty); raw PnL is never the sole signal (L7)
- **Episode/TrajectoryHandle**: episode identity = (environment id, world config hash, seed, body/substrate refs, start/end conditions); deterministic replay of an episode must be possible given the same identity + world version (L9)
- **EnvironmentError taxonomy**: typed errors (invalid action, world exhausted, boundary violation…)
- **Registration**: environment kind registry (id -> factory descriptor), versioned

### services/environment-runner — the runner skeleton

A minimal, dependency-free service package (no HTTP server this wave — a library + CLI entry that can run an episode locally):

- Load an environment descriptor + config, run N episodes with a scripted/random policy (a `RandomPolicy` test double implementing a minimal Policy contract you define), collect trajectory summaries (episode id, steps, terminal reason, reward components)
- Deterministic: same config + seed -> identical trajectory summary (hash it)
- Emit a `run-manifest.json` artifact format binding: environment id/version, world config hash, seed, policy id, step count, trajectory summary hash — the lineage seed for T011/T014

### contracts/environment — the human-readable contract docs

Markdown docs: the environment interface reference (reset/step/observation/action semantics), fidelity mode contract, reward spec contract, episode lineage/manifest contract, JSON examples. These are the authority for T009 (replay world), T013 (RL bridge), T014 (distributed episodes).
