## DESIGN GUIDANCE (the Lead's calibration — bake these in)

- ONE credential authority: the `auth` module. Your credential-service follows the membership-service house pattern (application service + neutral port + SQL/in-memory adapters + public barrel export). The console holds ZERO credential state of its own — it projects the public API exactly as validation-lab projects the validation corpus.
- Credential records carry identity, label, application/tenant scope, role/permission scope, creation/rotation timestamps, status (active/retired/revoked). Secret material lives ONLY as a `SecretReference` through the platform secret-store (classification `provider-credential`/`signing-key`) — never in the record, never in a wire shape, never in a log line.
- Issuance returns the secret EXACTLY ONCE; no later route, log or render path can retrieve it. Rotation issues a successor under the same credential identity and retires the predecessor; revocation is immediate and idempotent. Every mutation honors `assertScopeCovers` and the house idempotency discipline.
- Routes follow the executions.ts facade: `Idempotency-Key` required on POSTs, scope-checked reads, strict body-key rejection, serialization-boundary redaction. Register in the API server; sync openapi.json + env-vars.json (names, never values) + the route-count pin (additive rows only — DEP-001's identity route shares this table; the Lead reconciles at merge).
- Console flows: Issue (guided form → show-once reveal with copy affordance + "you will not see this again" contract; honest unavailable state when issuance is not enabled for the deployment) → List (metadata only, explicit boundary rows naming facts the public API does not carry, e.g. last-used telemetry) → Rotate/revoke (confirm-then-act, idempotent semantics, status transitions rendered from the authority) → Connections (BYO connection facts from public records composed with the existing safe-credential-rules vocabulary; zero secret values).
- Honesty doctrine: missing facts render as honest unavailable states NAMING the missing public contract — never invented. The redaction doctrine (`[not displayed]`) + hostile-value probes cover every new render path.
- Responsive + accessibility: keyboard paths for issue → reveal → list → rotate → revoke, labeled controls, honest empty/error states. House test style (vitest, `tests/unit/**`).
