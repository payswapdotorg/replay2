## DESIGN GUIDANCE (the Lead's calibration — bake these in)

- ONE budget authority: the `budgets` module. Your quota/lifecycle service follows the budget-service house pattern (application service + neutral port + SQL/in-memory adapters + public barrel rows). The console holds ZERO quota/policy state — it projects your public routes exactly as validation-lab projects the validation corpus.
- Quota dimensions: spend (resolves through the existing `BudgetAuthority` fail-closed), wall-clock time, concurrent runs, artifact count/size (enforce at sandbox admission with the same fail-closed discipline). An unenforceable dimension fails admission honestly — never default-allow.
- Expiration: TTL on sandbox identities; expiry transitions are events on the EXISTING executions EventEnvelope ledger (no new ledger); post-expiry reads render honest expired states — records never silently disappear.
- Reset: idempotent, confirmable, per-identity, auditable, and carries NOTHING forward — a fresh admission under fresh budgets. Probe-test both the idempotency (second reset = no-op success) and the state-non-carrying.
- The synthetic-data policy is a VERSIONED PLATFORM ARTIFACT served through a public route: permitted data classes (synthetic fixtures only — never real PII/secrets/credentials/production data), enforcement points (admission data-class check + the DEP-013 composer), violation recording (facts: class + decision, never payloads). One source of truth — the console renders the served document, never a copy.
- Routes follow the executions.ts facade: `Idempotency-Key` required on POSTs, scope-checked reads, strict body-key rejection, serialization-boundary redaction; cross-scope attempts fail with house `TENANT_SCOPE_VIOLATION` semantics.
- Console: quotas view (every dimension, limit/consumption/window/status, boundary rows naming non-exposed facts), expiration/reset flows (confirm-then-act, "nothing carries forward" contract visible), policy render. Honesty doctrine: missing facts render as honest unavailable states NAMING the missing public contract. Responsive + accessibility: keyboard paths, labeled controls, honest empty/error states. House test style (vitest, `tests/unit/**`).
