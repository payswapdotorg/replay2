### packages/market-protocol — the canonical provider-neutral event envelope

Every external market observation enters TradRL as one canonical event shape. At minimum:

```
event_id, venue, instrument, asset_class, event_type,
event_time, source_time (where known), available_time, ingestion_time,
sequence, provider, provenance, payload
```

Required:

- **MarketEvent envelope** with the availability quartet (event/source/available/ingestion) as REQUIRED fields with explicit semantics: `event_time` = when it happened in the world; `source_time` = when the source says it happened; `available_time` = the earliest an agent may legitimately observe it (the information boundary input); `ingestion_time` = when TradRL actually received it
- **EventType taxonomy** — discriminated union covering at least: trade, quote, book snapshot, book delta, ohlcv/bar, news, macro release, social signal, fundamental, derivative/option chain mark, and an `other` escape hatch with a required free-form kind
- **Provenance** — provider id, adapter id/Version, synthetic flag (events generated by simulation MUST be distinguishable from historical ones: `provenance.origin: historical | simulated | generated`), and a lineage/id chain for derived events
- **Sequence discipline** — per (venue, instrument, event stream) monotonic sequence helpers and validation
- **Typed payloads** — a payload registry keyed by event type (trade payload, quote payload, book payload…), each with its own guard; no `unknown` leaks at the API surface
- **Guards** — hand-rolled runtime guards for envelope + payloads; invalid envelopes (missing availability times, non-monotonic timestamps where the contract demands order, unknown event types) must fail validation with typed errors

### packages/time-engine — the point-in-time information boundary

- **SimulationClock** — now, asOf, playback speed, pause/resume state, fidelity mode (exact replay | reactive replay | generative — L5: these are DISTINCT)
- **TimeBoundary / information firewall** — the predicate at the heart of the system: at simulation time `t`, an agent may observe an event iff `event.available_time <= t`. Provide a `VisibilityFilter` that takes events + a clock and yields the observable subset, plus a `leakageCheck` that scans a trajectory of (clock, observed events) and reports any observation that violated the boundary
- **Derived-state rule** — the same firewall applies to derived features, aggregates, labels and cached data: provide the timestamp contract types that derived artifacts must carry (their own `available_time` = latest input availability + computation policy) so the firewall can police them uniformly
- **Time arithmetic** — monotonic timestamp comparisons, `T - x minutes` helpers, explicit historical-timestamp anchoring; all comparisons via the engine (no raw comparisons scattered in consumer code)

Cross-lane rule: trading domain entities (Order, Portfolio…) are T002's lane and agent body/substrate types are T003's lane. Reference them ONLY by opaque string ids; never import their packages (they do not exist yet and must not be added to your deps).

`contracts/market/` must contain markdown contracts: the envelope field table with semantics per field, the availability quartet contract, the event type taxonomy, the provenance/syntheticity rules, the Time Machine/visibility contract, and JSON examples. These docs are the authority for ingestion (T008), the adapter SDK (T036), the knowledge firewall (T026) — precision beats volume.
