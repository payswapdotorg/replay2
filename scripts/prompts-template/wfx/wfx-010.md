## 3. Task packet

**WFX-010 — Entertainment Graph.** Build `packages/domain/src/graph/` (Lane A
private path). The graph is the canonical content model — one EntertainmentItem
identity, many SourceRealizations:

1. `src/graph/model.ts` — graph entities extending the frozen types:
   `Creator { id: CreatorId; name: string; kind: 'person'|'group'|'channel'|'studio'; }`
   (add `wfxcre_` ID brand in your own module — do NOT edit ids.ts),
   `Topic { id: TopicId; label: string; }` (`wfxtop_`),
   `ItemRelationship { fromItemId; toItemId; relation: 'partOf'|'sequelOf'|'prequelOf'|'sameSeries'|'relatedTo'|'adaptationOf'; }`,
   `GraphItem` = frozen `EntertainmentItem` + `{ creators: CreatorId[]; topics: TopicId[];
   realizations: SourceRealization[]; createdAt: string; updatedAt: string; }`,
   `GraphEvent` = frozen `EntertainmentEvent` + `{ envelopeId?: string }` reference.
2. `src/graph/store.ts` — `EntertainmentGraph` in-memory store with typed queries:
   `upsertItem(item)`, `upsertRealization(itemId, realization)` (no duplicates per
   (connectorId, externalRef) — dedupe by merge), `upsertCreator/upsertTopic`,
   `relate(fromItemId, toItemId, relation)`, queries: `item(id)`, `byCreator(creatorId)`,
   `byTopic(topicId)`, `search(titleSubstring)` (case-insensitive, on canonicalTitle),
   `realizationsOf(itemId)`, `neighbors(itemId)` (via relationships, one hop).
   All mutations validate via the existing `packages/domain/src/validation.ts`
   validators where applicable and throw typed `GraphError` (define it: invalid-input
   with detail) on bad input. Store methods are pure data operations — no I/O, no provider calls.
3. `src/graph/dedupe.ts` — canonicalization/deduplication: `dedupeKey(item)` =
   normalized title (lowercase, strip punctuation/diacritics, collapse whitespace) +
   canonicalType + optional duration bucket (±60s), `mergeCandidates(a, b)` predicate
   (same dedupeKey OR same external (connectorId, externalRef) via realizations),
   `mergeItems(primary, duplicate)` — merges realizations (dedupe), creators, topics
   (union), keeps earliest createdAt, latest updatedAt, prefers non-undefined titles.
4. `src/graph/index.ts` — barrel for the graph module.
5. Add EXACTLY ONE export line to `packages/domain/src/index.ts`:
   `export * from "./graph/index";` (another worker edits the same file adding their
   own line — keep your change to that single line, placed after the existing exports).
6. Tests (bun:test) under `packages/domain/tests/graph.test.ts`: model branding,
   store CRUD + queries (upsert/lookup/search/byCreator/byTopic/neighbors), realization
   dedupe on (connectorId, externalRef), relationship traversal, typed errors on bad input,
   dedupe (key generation normalization, merge predicate true/false cases, merge union
   semantics incl. earliest/latest timestamps).
