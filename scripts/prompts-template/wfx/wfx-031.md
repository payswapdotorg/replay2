## 3. Task packet

**WFX-031 — WebFlix recommendation model adapter.** The FIRST-PARTY,
REPLACEABLE recommendation strategy, packaged as (a) a `RecommendationModel`
for the OS and (b) a Model Fabric `ModelProvider` for the `recommendation`/
`ranking` tasks. Deterministic, explainable, local-only (privacy:
`local-only` — no network, ever). Realization:
`packages/model-fabric/src/wfx-model/`.

Build these modules (file names may differ; structure required):

1. **`model.ts`** — `createWfxRecommendationModel(version): RecommendationModel`:
   - `id: "wfx-first-party"`, `version` parameterized (semver string, validated).
   - `score(ctx)`: pure, deterministic, synchronous-Promise. Feature
     computation mirrors the OS `CandidateFeatures` contract (import the type
     from `@wfx/recommendation` — do not redefine). Scoring: typed weighted
     formula over intent-match (per scope with session scope weighted highest
     for the requested surface), freshness (recency decay — deterministic
     half-life), availability, fatigue penalty, exploration multiplier from
     policy, novelty multiplier. EVERY score carries `explanations[]` — one
     human-readable line per contributing term with its signed contribution
     (e.g. `"session-intent match 'sci-fi' +0.22"`, `"fatigue (3 recent
     repeats) -0.15"`) and `confidence` derived from feature completeness
     (missing features ⇒ lower confidence, never silent zeros).
   - Determinism: identical ctx ⇒ byte-identical output ordering (stable sort
     by score desc, then itemId asc).

2. **`provider.ts`** — `createWfxModelProvider(): ModelProvider`: Fabric
   adapter: `id: "wfx-first-party"`, `capabilities: ["recommendation",
   "ranking"]`, `invoke(task, input)` — validates input against the OS context
   shape (typed errors with field paths on mismatch), routes to the model,
   wraps scores in the Fabric's typed envelope, never throws raw. Privacy
   class: local-only enforced by construction (no network imports anywhere).

3. **`registry.ts`** — registration glue: `registerWfxModel(fabric)` —
   registers the provider for `recommendation` + `ranking` tasks with
   `privacy: "local-only"` and cost 0 (first-party, no metering — typed
   cost-report of zero, not undefined). Uses ONLY the MERGED WFX-030 public
   registry API.

4. **`replacability.ts`** — `ModelSwapContract`: a typed contract + test
   helper proving the OS never depends on THIS model specifically: the same
   OS pipeline runs against a stub model and the first-party model, both
   through the same interface (drift-proofing the replaceability invariant).
   Include `assertModelContract(model)` used by tests.

5. Tests in `packages/model-fabric/tests/wfx-model.test.ts` (bun:test):
   - Score determinism: fixed ctx → byte-identical outputs (run twice).
   - Explanation completeness: every non-zero contribution has a line;
     explanations sum-check (signed contributions ≈ score − base).
   - Surface weighting: session intent weighs more on `short` than `watch`
     for identical candidates (or documented equivalent).
   - Fatigue monotonicity: more repeats ⇒ lower score, all else equal.
   - Confidence: feature-missing ctx ⇒ lower confidence than complete ctx.
   - Provider: task validation errors typed with paths; envelope correctness;
     privacy local-only; zero-cost typed.
   - Registry: registers under both tasks; duplicate registration typed-refused.
   - Swap contract: OS pipeline output shape identical with stub vs first-party
     (interface parity, not value equality).
