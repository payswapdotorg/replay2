## 3. Task packet

**WFX-011 — Intent Graph.** Build `packages/domain/src/intent/` (Lane A private path):

1. `src/intent/model.ts` — intent entities extending the frozen `UserIntent`:
   `IntentRecord` = frozen UserIntent + `{ createdAt: string; updatedAt: string;
   lastReinforcedAt: string; evidenceCount: number; }` and the frozen scopes are
   the law: persistent | temporary | session | momentary | social. Also
   `IntentSnapshot { userId; takenAt; active: IntentRecord[]; }` — a point-in-time
   view of non-expired intents. Define `wfxint_`-branded `IntentId` helper in YOUR
   module (do NOT edit ids.ts).
2. `src/intent/store.ts` — `IntentGraph` in-memory store: `record(input)` (create or
   reinforce: same (userId, scope, objective) → bump weight/confidence/evidenceCount/
   lastReinforcedAt instead of duplicating), `get(id)`, `list(userId)`, `expire(id)`,
   `decay(now)` — applys time decay to weights for temporary/session/momentary scopes
   (half-life table: momentary 30min, session 8h, temporary 72h, persistent NO decay,
   social NO decay), `snapshot(userId, now)` — active intents only (not expired;
   momentary older than 1h excluded). Typed `IntentError` (invalid-input) on bad input.
   Objective strings are trimmed, non-empty, ≤200 chars; weight/confidence ∈ [0,1].
3. `src/intent/infer.ts` — evidence-based inference (this guards anti-tunnel-vision):
   `inferFromEvents(userId, events: EntertainmentEvent[], now)` → intent updates:
   'search' events infer intent from the query (payload.query or — absent that — a
   synthetic objective from the item), 'like'/'save' reinforce related intent,
   'complete' reinforces with LOWER weight than explicit signals (a watch is one
   signal, not an identity: complete → weight bump 0.05, like/save/search → 0.15).
   Inference NEVER narrows: it only adds/reinforces — it must NEVER delete or
   down-rank other intents (the anti-tunnel-vision law). Provenance = 'inferred'.
   Session scope for in-session signals, temporary for the rest.
4. `src/intent/policy.ts` — `RecommendationPolicy` helpers on the frozen type:
   `defaultPolicy(userId)` — balanced attention mode, exploration 0.2, novelty 0.2,
   socialInfluence 0.1, no session extension cap; `validatePolicy(p)` → typed result
   (weights in range, exploration/novelty/socialInfluence ∈ [0,1], objectives well-formed);
   `clampPolicy(p)` — bounds values into legal ranges (documents what it clamps).
5. `src/intent/index.ts` — barrel for the intent module.
6. Add EXACTLY ONE export line to `packages/domain/src/index.ts`:
   `export * from "./intent/index";` (another worker edits the same file adding their
   own line — keep your change to that single line, placed after the existing exports).
7. Tests (bun:test) under `packages/domain/tests/intent.test.ts`: model (record
   shape, snapshot excludes expired/momentary-stale), store (record + reinforce —
   no duplicate rows, weight/confidence bumps, evidenceCount; decay half-lives per
   scope incl. persistent/social immunity; expire; typed errors), inference (search
   event infers intent, complete reinforces LESS than like, inference never removes
   intents — the anti-tunnel-vision assertions, provenance='inferred', scope routing),
   policy (default shape, validate failures, clamping).
