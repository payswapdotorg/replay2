## 3. Task packet

**WFX-013 — Reference read-only connector.** The golden-path reference
implementation of the Connector SDK: a COMPLETE, DETERMINISTIC, read-only
connector over bundled fixture data. It demonstrates every contract behavior
new connector authors should copy. Realization: `packages/connectors/src/reference/`.

Build these modules (file names may differ; structure required):

1. **`descriptor.ts`** — `REFERENCE_CONNECTOR_DESCRIPTOR`: id
   `"wfx-reference"`, version `"0.1.0"`, displayName `"WebFlix Reference
   Source"`, auth `"none"`, capabilities EXACTLY
   `["catalogSearch","metadata","playEmbed","playBrowser","playExternal","availability","libraryRead"]` —
   deliberately read-only (no libraryWrite/like/save/download/transform: those
   return typed unsupported results).

2. **`data.ts`** — the fixture catalog: ≥10 `SourceItem`s across canonical types
   (movies, series, episode, video, short, post, audio), each with ≥1
   `PlaybackRealization` (mix of embed/browser/external modes), deterministic
   availability (`available`/`unavailable`/`unknown`), NO randomness, NO network.
   Search index: tokenized title + topic strings, case-insensitive.

3. **`connector.ts`** — `createReferenceConnector(): SourceConnector`
   implementing every SDK method:
   - `search` — deterministic tokenized matching, empty query ⇒ empty result
     (typed ok), results are `SearchResult` extension types with a stable rank.
   - `metadata` — known ref ⇒ `SourceItem`; unknown ref ⇒ typed ok-null (NEVER
     throw for a miss).
   - `resolve` — realizations for a ref ordered by the frozen precedence
     hint (embed before browser before external — NATIVE is unsupported for this
     source and therefore ABSENT); unknown ref ⇒ ok-empty.
   - `executeAction` — the connector is read-only: EVERY user action returns a
     typed UNSUPPORTED result via the WFX-003 ConnectorResult convention
     (like/save/follow/comment all unsupported with a clear reason string).
   - `readLibrary` — returns the fixture "saved" list (deterministic).
   - `writeLibrary` — absent (optional method NOT implemented — descriptor
     lacks `libraryWrite`).
   - All methods validate `ConnectorContext` (userId non-empty, locale non-empty)
     with typed invalid-input errors.

4. **`lifecycle.ts` extension** — NO. Do not edit the SDK lifecycle. Instead
   `lifecycle-demo.ts`: a pure demonstration that the reference connector
   transitions cleanly through the WFX-003 FSM (created → initialized →
   disposed) and that operations on a disposed connector return typed
   lifecycle errors (not throws, where the SDK convention says so).

5. **`index.ts`** — barrel: descriptor, connector factory, fixture data exports.

6. Tests in `packages/connectors/tests/reference.test.ts` (bun:test):
   - capability honesty: descriptor caps vs actual method support matrix
     (every advertised capability works; every unadvertised one is typed-unsupported)
   - search/metadata/resolve golden paths AND miss paths (ok-empty / ok-null)
   - read-only enforcement: all mutating actions typed unsupported
   - context validation errors
   - lifecycle demo transitions
