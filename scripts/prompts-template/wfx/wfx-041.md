## 3. Task packet

**WFX-041 — QoE/recommendation telemetry.** The typed telemetry layer that
turns pipeline traces, session health, and feed engagement into PRIVACY-
PRESERVING, aggregateable metrics + compliance reports. Pure TypeScript:
metric types, derivation functions, windowed aggregation, redaction, and a
typed sink contract. NO network, NO persistence (sink injected).
Realization: `packages/recommendation/src/telemetry/`.

Build these modules (file names may differ; structure required):

1. **`metrics.ts`** — typed metric units:
   - QoE: `RebufferRatio` (stallMs / watchMs per session), `JoinTimeMs`
     (start→first progress), `SeekLatencyMs`, `QualitySwitchCount`,
     `BufferHealthMs` percentiles (p50/p95 — deterministic interpolation,
     documented method).
   - Recommendation: `ExplanationCoverage` (share of feed cards carrying
     non-empty explanations), `DiversityIndex` (distinct dominant intents per
     feed / feed size), `AttentionModeCompliance` (violations of mindful/
     immersive constraints observed = MUST be 0 — the compliance signal),
     `CandidateSurvival` (share of retrieved candidates surviving to feed —
     anti-tunnel-vision indicator), `RerankFrequency`.
   - Engagement: skip/complete/like/save rates per surface.
   Every metric: typed value + provenance (source trace id / event id range) +
   computedAt (injected clock).

2. **`derive.ts`** — pure derivation from the merged artifacts:
   `deriveQoe(sessionTrail)`, `deriveRecommendation(pipelineTraces)`,
   `deriveEngagement(events)` — consuming the ACTUAL merged trace/event types
   (imported). Missing fields ⇒ typed `degraded` metric markers (provenance
   says which field was absent) — never fabricated values.

3. **`aggregate.ts`** — windowed aggregation: `WindowedAggregator` (pure):
   rolling windows by time bucket (bucket size injected), merge-safe (combine
   two aggregations of the same window idempotently — associativity TESTED),
   percentile merge uses the deterministic t-digest-free method (bounded
   sketch: sorted sample with fixed cap — document the approximation).

4. **`redact.ts`** — privacy: `redactMetrics(aggregate, level)`:
   `full` ⇒ as-is; `internal` ⇒ drop free-text explanations, keep counts;
   `shared` ⇒ userIds bucketed into cohorts (deterministic hash bucket),
   small-n suppression (<5 samples ⇒ suppressed with typed marker — no
   misleading rates). RedactionReport lists every transformation (auditable).

5. **`sink.ts`** — `TelemetrySink` port + `createRecorderSink()` (in-memory,
   replayable) + `telemetryReport(aggregate, window)` — a typed, serializable
   report document (schema-versioned) ready for dashboards.

6. Tests in `packages/recommendation/tests/telemetry.test.ts` (bun:test):
   - Derivation goldens from fixture traces/events (including a degraded case).
   - Percentile determinism + documented interpolation.
   - Aggregation: window bucketing exact; merge associativity (a+b)+c ==
     a+(b+c) byte-identical reports.
   - AttentionModeCompliance: a crafted violating trace ⇒ violation count > 0
     (the metric MUST catch violations); compliant traces ⇒ 0.
   - CandidateSurvival: anti-tunnel-vision fixture ⇒ high survival; narrowing
     fixture ⇒ low survival + the signal visible.
   - Redaction: each level's transformations + small-n suppression typed.
   - Report serialization round-trip (JSON.parse(JSON.stringify) equality).
