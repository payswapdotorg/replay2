## 3. Task packet

**WFX-030 — Model Fabric.** Build `packages/model-fabric/src/` — the provider-neutral
model gateway. NO real model providers in this item: the fabric routes to REGISTERED
providers; concrete cloud/local providers arrive in later work items. This item is
the routing/policy/cost/tracing machinery:

1. `src/types.ts` — extend the frozen types: `FabricResult<T> = { ok: true; value: T;
   trace: InvocationTrace } | { ok: false; error: FabricError }`;
   `FabricError` union: `{ kind: 'no-provider'; task: ModelTask } | { kind: 'policy';
   detail: string } | { kind: 'privacy'; detail: string } | { kind: 'cost'; budget:
   number; spent: number } | { kind: 'provider-error'; providerId: string; detail:
   string } | { kind: 'timeout'; providerId: string; ms: number }`;
   `InvocationTrace { invocationId; taskId; providerId; startedAt; durationMs; cost?:
   number; fallbacks: string[] }`.
2. `src/registry.ts` — `ModelFabricRegistry`: register(provider: ModelProvider) with
   capability indexing (register by ModelTask), `providersFor(task)`, duplicate-id
   rejection, `describe()` (id × task matrix).
3. `src/router.ts` — `ModelRouter`: `route(task, policy): RoutePlan` where RoutePlan =
   ordered [preferred? + fallbacks] filtered by (a) task capability, (b) privacy: policy
   'local-only' excludes providers not registered with `privacy: 'local'` (extend
   provider metadata with a `privacy: 'local' | 'cloud'` registration field — document
   it), (c) cost: providers whose declared `costPerOperation(task)` exceeds policy
   `maxCostPerOperation` are excluded. Empty plan → typed no-provider error at invoke time.
4. `src/fabric.ts` — `ModelFabric` (the gateway): `invoke<TIn, TOut>(task, input,
   policy?, context?)` — resolves the route plan, tries providers in order, enforces
   a per-invocation timeout (default 30s, per-provider), collects the trace, applies
   fallback on provider-error/timeout, and returns the FIRST success with the full
   fallback chain recorded. Cost accounting: sum declared costs across attempted
   providers; if a policy budget exists and would be exceeded BEFORE an attempt,
   skip that provider (typed cost error only if ALL are skipped). Privacy enforcement:
   for 'local-only' policies, if input must go to a cloud provider the router already
   excluded them — invoke double-checks and returns a typed privacy error rather than
   leaking (defense in depth).
5. `src/testing.ts` — TEST FIXTURES ONLY: `makeEchoProvider(id, opts)` (returns input
   transformed by a stub function, declares chosen capabilities/privacy/costs),
   `makeFailingProvider(id, opts)` (always provider-error or timeout),
   `makeSlowProvider(id, ms)` (sleeps past the timeout). Clearly named/typed as test
   fixtures; never production providers.
6. `src/index.ts` — public entry.
7. Tests (bun:test) under `packages/model-fabric/tests/`: types (error shapes/guards),
   registry (indexing, dedupe, matrix), router (capability filter, privacy exclusion —
   local-only never routes to cloud, cost exclusion, preferred-then-fallback order),
   fabric (happy path with trace; fallback on failing provider; timeout → next
   provider; all-fail → provider-error with full chain; no-provider typed error;
   cost budget skip; privacy defense-in-depth error; duplicate invocations get
   distinct invocationIds).
