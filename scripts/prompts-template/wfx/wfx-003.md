## 3. Task packet

**WFX-003 — Connector SDK.** Build `packages/connectors/src/` on top of the frozen
`SourceConnector` contract:

1. `src/result.ts` — explicit result type used across the SDK:
   `ConnectorResult<T> = { ok: true; value: T } | { ok: false; error: ConnectorError }`
   where `ConnectorError` is a discriminated union: `{ kind: "unsupported";
   capability: Capability; detail?: string } | { kind: "unauthorized"; connectorId:
   string } | { kind: "transport"; connectorId: string; detail: string } | { kind:
   "invalid-input"; detail: string }`. Constructors + type guards for each.
   EVERY operation that a connector does not declare capability for MUST return
   `{ ok: false, error: { kind: "unsupported", ... } }` — never throw, never fake.
2. `src/descriptor.ts` — `defineDescriptor(input): ConnectorDescriptor` with strict
   runtime validation: id (kebab-case, stable), version (semver), displayName,
   capabilities must be members of the frozen `Capability` union (validate against
   the exported frozen `CAPABILITIES` constant — define that constant here from the
   frozen contract's `Capability` type), auth mode.
3. `src/lifecycle.ts` — connector lifecycle state machine: `registered →
   initialized → disposed` (plus `failed` terminal). `ConnectorLifecycle` class or
   module with `initialize()`, `dispose()`, `state()`, and a guard helper
   `assertOperational(state)` that throws a typed `LifecycleError` when called in
   the wrong state. Illegal transitions are rejected, not ignored.
4. `src/base.ts` — `abstract class BaseConnector implements SourceConnector`:
   holds descriptor + lifecycle; implements `descriptor()`; provides protected
   `requireCapability(cap)` returning `ConnectorResult`-friendly unsupported errors;
   concrete classes extend it and implement search/metadata/resolve/executeAction
   (+ optional readLibrary/writeLibrary) returning `ConnectorResult`-wrapped values
   through adapter helpers (`asyncResult()` wrapper so implementations can return
   plain values OR typed errors uniformly — design it, document it).
5. `src/registry.ts` — `ConnectorRegistry`: register(descriptor/instance),
   `get(id)`, `all()`, `withCapability(cap): SourceConnector[]`, `capabilityMatrix()`
   (id × capability truth table for UI honesty). Duplicate id registration throws.
6. `src/testing.ts` — `makeStubConnector(overrides?)`: an in-memory test double
   built on BaseConnector, clearly named/typed as a TEST FIXTURE (descriptor id
   `stub-test`), with canned search/metadata/resolve results and an intentionally
   limited capability set so unsupported-paths are testable. It is never to be
   registered as a production source.
7. `src/index.ts` — public entry re-exporting everything above.
8. Tests (bun:test) under `packages/connectors/tests/`: result (unsupported/
   unauthorized/transport/invalid-input shapes), descriptor validation (bad id,
   bad capability, missing fields), lifecycle (legal/illegal transitions),
   base connector (requireCapability enforcement — calling an undeclared
   capability yields typed unsupported, NOT a throw), registry (register, dedupe,
   capability queries, matrix), stub connector end-to-end (search returns canned,
   undeclared op returns unsupported). Also import-check: `import ... from
   "@wfx/domain"` resolves (lane-check covers it, but assert the types compile).
