## 3. Task packet

**WFX-021 — Recommendation OS.** The full ranking pipeline as PURE TypeScript:
retrieval -> features -> scoring -> policy -> intent-aware diversity -> feed
composition. Models are INJECTED (the frozen `RecommendationModel` interface);
you ship a deterministic heuristic default model. No I/O, no network, no
persistence. Realization: `packages/recommendation/src/os/`.

Build these modules (file names may differ; structure required):

1. **`pipeline.ts`** — `runRecommendation(ctx: RecommendationContext): FeedPage`
   orchestrating the stages in order, each stage a pure function consuming the
   previous output. Every stage's decision is recorded in an auditable
   `PipelineTrace` (stage name, input count, output count, policy decisions) —
   recommendations must be EXPLAINABLE end-to-end.

2. **`features.ts`** — feature assembly: `assembleFeatures(ctx)` producing per
   candidate a typed `CandidateFeatures` record: intent-match score per scope,
   freshness (age vs now), repetition count (from `recentEvents`), fatigue
   signal (repetition × recency decay), source availability ratio (realizations
   available/total), duration/orientation fit for the requested surface,
   exploration flag (unseen topic vs seen), social signal strength. Deterministic
   — every feature computable from `ctx` alone.

3. **`scoring.ts`** — `score(ctx, features, model)` — invokes the INJECTED
   `RecommendationModel.score()` (frozen interface). Ships
   `createHeuristicModel(): RecommendationModel` — a deterministic,
   explainable default: weighted linear combination of features with
   `explanations` for every contributing term (e.g. "matches session intent
   'sci-fi' +0.22"). The default model MUST respect policy weights
   (exploration/novelty/socialInfluence) as multipliers on their features.

4. **`policy.ts`** — policy constraints: `applyPolicy(ctx, scored)` —
   - Deduplicate canonical items (same entertainmentItemId).
   - Availability floor: candidates with zero available realizations drop to
     the tail (NOT deleted — surface-agnostic retrieval preserved; the trace
     records the demotion).
   - Attention mode: `mindful` inserts a mandatory diversity gap every N items
     and caps session-extending chains; `immersive` allows chains but never
     REMOVES alternatives; `balanced` = default; `custom` uses explicit
     objective weights from `RecommendationPolicy.objectives` (maximize/
     minimize direction honored). NEVER silently optimize session length against
     the selected mode — this is the attention-policy LAW.
   - Max session extension minutes respected when provided.

5. **`diversity.ts`** — intent-aware diversity: `diversify(scored, intents)` —
   greedy re-ranking that prevents topic/intent monoculture: no more than K
   consecutive items sharing the same dominant matched objective; injects
   exploration candidates when the top block concentrates >X% on one intent
   (K and X derived from policy exploration weight — deterministic formulas,
   documented). NEVER deletes candidates outright — reorder/demote only
   (anti-tunnel-vision: the pool stays wide).

6. **`composition.ts`** — feed composition: `composeFeed(surface, ranked, ctx)`:
   - `'watch'` (long-form): episodic continuity (next-episode adjacency when
     graph relations say so), resume-aware ordering, longer items preferred.
   - `'short'`: vertical/orientation `vertical`-first, rapid replacement
     ordering, shorter items preferred, session-aware boost.
   - Output `FeedPage` typed for the surface with per-card position reasons in
     the trace.
   - Feed mode from content + session context ONLY — never from source.

7. **`fatigue.ts`** (if not folded into features) — repetition/fatigue:
   typed signals, tested monotonicity (more repeats ⇒ higher fatigue ⇒ lower
   rank, all else equal).

8. **`index.ts` additions** — export the pipeline, model factory, types, trace.

9. Tests in `packages/recommendation/tests/os.test.ts` (bun:test), MUST include:
   - **Anti-tunnel-vision tests**: a user with 10+ watches of ONE topic still
     receives non-that-topic candidates in the feed; profile narrowing
     impossible by construction (assert diversity invariants).
   - Attention-policy tests: mindful mode never produces unbroken chains;
     immersive mode keeps alternatives present; no mode silently drops
     candidates to extend sessions.
   - Policy objectives: maximize/minimize directions honored.
   - Pipeline trace completeness: every stage recorded, every demotion
     explained.
   - Deterministic golden outputs (fixed ctx → fixed feed).
   - Surface rules: watch vs short composition differences.
   - Injected-model contract: a stub model's scores flow through unchanged
     (the OS never overrides model scores silently — policy decisions are
     recorded separately in the trace).
