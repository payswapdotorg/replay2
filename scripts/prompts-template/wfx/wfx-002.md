## 3. Task packet

**WFX-002 — Shared domain types + event envelope.** The frozen contracts already
define the core interfaces (EntertainmentItem, EntertainmentEvent, Capability,
PlaybackMode, PlaybackRealization, PlaybackSession, etc. — re-exported from
`@wfx/domain`). You build the domain layer AROUND them, inside `packages/domain/src/`:

1. `src/ids.ts` — canonical ID scheme: prefixed, verifiable string IDs for
   entertainment items (`wfxitm_`), source realizations (`wfxsrc_`), events
   (`wfxevt_`), playback sessions (`wfxpses_`), intents (`wfxint_`), plus
   `is*Id` type guards and a shared ULID-style generator (timestamp + randomness,
   sortable, no external dependency). IDs are opaque strings at the contract
   level; your scheme is the canonical production format.
2. `src/events.ts` — event envelope: `EventEnvelope { schemaVersion, eventId,
   occurredAt, event }` wrapping the frozen `EntertainmentEvent`, with
   `makeEvent(...)` factory (fills id/timestamp/sessionId), `envelope(event)`,
   `SCHEMA_VERSION`, and `envelopeFromRaw` safe-parse for untrusted input.
3. `src/device.ts` — `DeviceCapabilities { playbackModes: PlaybackMode[];
   codecs: string[]; browser: boolean; backgroundPlayback: boolean;
   storageBytes?: number; casting: boolean }` + `canPlay(capabilities, mode)` and
   a couple of sensible presets (modern-web, desktop-native) as fixtures.
4. `src/validation.ts` — a small hand-rolled runtime validator (NO external
   dependency): `validateEntertainmentItem`, `validateEntertainmentEvent`,
   `validateSourceRealization`, `validatePlaybackRealization` returning
   `{ ok: true, value } | { ok: false, errors: string[] }` — checking required
   fields, enum membership (canonicalType, orientation, playback mode,
   availability, event type), and ID prefix where applicable.
5. Export everything from `packages/domain/src/index.ts` (it already re-exports
   the frozen + extension contracts; ADD your exports, keep the existing lines).
6. Tests (bun:test) under `packages/domain/tests/`: ids (format, uniqueness,
   guards), events (factory fills fields, envelope wraps, safe-parse rejects
   malformed), device (canPlay matrix), validation (one pass + several failure
   cases per validator, including enum violations).
