## 3. Task packet

**WFX-025 — Media Surface resolver.** The pure decision engine that picks the
realization mode for a playback request given device capabilities, realization
availability, and source permissions. TypeScript types + pure logic + fixtures
ONLY — no browser embedding, no players, no UI. Realization:
`packages/experience/src/surface/`.

Build these modules (file names may differ; structure required):

1. **`request.ts`** — `SurfaceRequest`:
   `{ item: EntertainmentItem; realizations: PlaybackRealization[]; device: DeviceCapabilities; permissions: SurfacePermissions; now: string; }`
   where `SurfacePermissions` is a typed record per mode
   (e.g. `browserAllowed`, `externalAllowed`, `nativePermitted` — defaults true
   except explicit restriction) plus optional provider hints.

2. **`resolve.ts`** — `resolveSurface(request): SurfaceResolution` — THE frozen
   precedence, implemented exactly:
   - Filter realizations by availability (`available` only; `unknown`/`unavailable`
     excluded — record every exclusion with a REASON).
   - Native: realization mode native AND device `canPlay` for the item's demands
     (codec/container from capabilities) AND nativePermitted.
   - Embed: mode embed AND device supports embedding.
   - Browser: mode browser AND `browserAllowed`.
   - External: mode external AND `externalAllowed` — the final fallback when at
     least one realization exists, even if restricted; a total dead end yields
     typed `unresolvable` with ALL exclusion reasons.
   - Output `SurfaceResolution`:
     `{ ok: true; chosen: PlaybackRealization; mode: PlaybackMode; precedenceTrace: string[] } | { ok: false; kind: "unresolvable"; reasons: string[] }` —
     the trace shows WHY each mode was accepted/rejected (auditable decisions).
   - Expired realizations (`expiresAt` in the past) are excluded with reason.

3. **`session-builder.ts`** — `buildPlaybackSession(resolution, userId, sessionId,
   resumePositionMs, clock)` — constructs the frozen `PlaybackSession` with a
   validated id and createdAt from the injected clock (no hidden `Date.now`).
   Rejects unresolvable input with typed errors.

4. **`matrix.ts`** — `capabilityMatrix()` — pure data: for every
   (mode × device-profile) pair, the decision outcome — used by tests and later
   by WFX-043 release acceptance. Device profiles: `tv-native`, `desktop-full`,
   `mobile-restricted`, `kiosk-browser-only`.

5. **`fixtures.ts`** — deterministic fixtures: items across canonical types,
   realizations in all 4 modes, devices from the profiles, permission sets
   (permissive, browser-blocked, all-restricted). NO randomness.

6. Tests in `packages/experience/tests/surface.test.ts` (bun:test):
   - precedence: native beats embed beats browser beats external when all available
   - each fallback step when the preferred mode is missing/unavailable/expired
   - device gating: native skipped when `canPlay` false
   - permission gating: browser/external restrictions honored
   - unresolvable: zero realizations ⇒ typed reasons for every mode
   - expired realization exclusion
   - session builder golden paths + validation errors
   - matrix consistency vs the resolver (no contradictions)
