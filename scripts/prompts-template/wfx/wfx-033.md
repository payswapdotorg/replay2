## 3. Task packet

**WFX-033 — Media transformation tools.** The typed tool layer that expresses
media transformations as Model Fabric invocations with PERMISSION enforcement.
Pure TypeScript: schemas, validators, permission logic, deterministic fake
providers for tests. NO actual media processing (no FFmpeg calls — those belong
to the native/adapter layers). Realization: `packages/model-fabric/src/transform/`.

Build these modules (file names may differ; structure required):

1. **`tasks.ts`** — typed task descriptors for each transformation:
   `TranscriptTask`, `TranslationTask`, `SubtitleTask`, `SummaryTask`,
   `SpeechTask` (textToSpeech), `TranscribeTask` (speechToText),
   `DubbingTask`, `CommentaryTask`. Each: input schema (typed, validated),
   output type, capability requirements, cost class (token/byte/second-based
   estimate function — deterministic estimates only).

2. **`permissions.ts`** — `TransformationPermissions`:
   - Input: media provenance record (authorized-source flag, license flags:
     `allowsTranslation`, `allowsDubbing`, `allowsCommentary`, `allowsTranscript`)
     + the requested task.
   - Output: `{ allowed: boolean; reason: string }` typed verdict with EVERY
     denial carrying an actionable reason (e.g. "dubbing requires
     allowsDubbing license flag — source wfx-reference marks it false").
   - HARD LAWS (encode + test): transformation of unauthorized media is ALWAYS
     denied; DRM-protected inputs denied; dubbing/commentary require explicit
     license flags. There is NO code path that bypasses the permission check.

3. **`pipeline.ts`** — `runTransformation(fabric, task, input)`:
   - Validates input against the task schema (typed errors with field paths).
   - Checks permissions FIRST (fail fast with the typed verdict).
   - Routes through the Model Fabric (task registry + policy: privacy class,
     provider fallback, cost ceiling — all Fabric semantics, reused).
   - Returns a typed `TransformationReceipt`: output, provider used, cost
     estimate, duration estimate, permission verdict echo, and a trace
     (fabric tracing reused, never duplicated).

4. **`subtitle.ts`** — subtitle-specific composition: timed-cue types
   (`SubtitleCue { startMs; endMs; text }`), validators (monotonic, non-
   overlapping, non-empty text), and pure builders that compose cues from
   transcript segments + translation outputs. VTT serialization as a pure
   string function (no file I/O).

5. **`fakes.ts`** — deterministic fake transformation providers implementing
   the Fabric `ModelProvider` interface for every transformation task:
   identity-translation (deterministic prefix), fixed-summary (first-N
   sentences), cue-generating transcript fakes. NO randomness, NO network.

6. Tests in `packages/model-fabric/tests/transform.test.ts` (bun:test):
   - Permission matrix: every task × every license combination — golden verdicts.
   - Hard laws: unauthorized media ALWAYS denied (exhaustive over tasks).
   - Schema validation: malformed inputs produce typed field-path errors.
   - Pipeline: permission denial short-circuits (fabric never invoked —
     observable via a counting fake).
   - Fabric routing: privacy class + fallback order honored (first provider
     fails ⇒ second used, all recorded in the trace).
   - Subtitle composition: monotonicity, overlap rejection, VTT golden output.
   - Cost estimates: deterministic and bounded by policy ceilings (over-ceiling
     ⇒ typed denial, never silent overrun).
